# 更新日志

版本后缀 `r` 表示提供安装包的试用构建，`t` 表示仅源码构建。VS Code 扩展清单保留数字版本，完整构建号记录在 `paperReviewBuild`；安装同一数字版本的新构建时需覆盖安装并重新加载窗口。

## 0.3.9r4 — 2026-10-23

- README 改为不绑定版本的使用指南，仓库与扩展内说明保持一致。
- 统一界面、设置及文档中的术语和名称，精简重复提示与常用菜单。
- 公开仓库移除测试代码、PowerShell 测试启动器及验证报告，本地保留。
- 整理 API、运行时、编译、PDF、Agent 和 Web 说明，更新仓库 About。
- 未修改 Master 合并、审计、持久化及冲突队列逻辑。

## 0.3.9r3 — 2026-10-23

- 增加可见的冲突入口和合并结果提交按钮。
- 冲突处理中冻结当前参与版本，新提交按不可变快照进入 Pending 队列。
- 合并完成后同步 Master 与 Human Draft，隐藏已解决冲突并继续处理 Pending。
- 支持重启恢复当前冲突、已保存结果和已接收提交。
- 以当前源码快照首次公开仓库，安装包通过 GitHub Releases 分发。
